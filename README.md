Image files used by the PFC Demo application (PEAT), including its split bar cursor (`split.cur`), and `peat.pbr`, its resource file.

## Which versions of PFC use these files

| Version | Its images |
|---|---|
| [2022](https://github.com/OpenSourcePFCLibraries/2022) | **This repository.** Add its folder to the system path or to PowerBuilder's application path; PEAT's project names `peat.pbr`. |
| [2019](https://github.com/OpenSourcePFCLibraries/2019) | The same images, in that repository. It doesn't need this repository. |
| [2025-Solution](https://github.com/OpenSourcePFCLibraries/2025-Solution) and [2025-Workspace](https://github.com/OpenSourcePFCLibraries/2025-Workspace) | Current images (Fluent UI System Icons) in `demoapp/images`; the split bar uses PowerBuilder's built-in `SizeWE!` pointer. They don't use this repository. |
